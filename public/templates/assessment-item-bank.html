Assessment Item Bank Overview

This assessment item bank contains a comprehensive collection of assessment items aligned with the learning objectives of the Data Security Compliance Training program. Each assessment item includes detailed metadata for tracking, analysis, and continuous improvement.

The bank is organized by module and learning objective, with items categorized by:

  • Question type
  • Cognitive level (Bloom's Taxonomy)
  • Difficulty level
  • Performance domain
  • Item usage statistics

This structure enables strategic assessment design, adaptive testing capabilities, and detailed performance analysis.

Learning Objective 1.2: Explain the organization's compliance obligations under each regulation

Item ID: MOD1-OBJ2-SA-001

Question Type Short Answer
Question Stem Explain our organization's three primary obligations under the Gramm-Leach-Bliley Act (GLBA) Safeguards Rule.
Model Answer Under the GLBA Safeguards Rule, our organization has three primary obligations:

1. Develop, implement, and maintain a comprehensive information security program that contains administrative, technical, and physical safeguards appropriate to our size, complexity, and the nature of our activities.

2. Regularly assess and address the risks to customer information in each relevant area of our operations, particularly in three areas: employee training and management; information systems; and detecting, preventing and responding to attacks, intrusions, or other system failures.

3. Evaluate and adjust the program in light of relevant circumstances, including changes in business operations or the results of security testing and monitoring.

Module 2: Data Classification

Learning Objective 2.1: Differentiate between the four levels of data classification

Item ID: MOD2-OBJ1-MC-001

Question Type Multiple Choice
Question Stem Which of the following characteristics distinguishes Confidential data from Restricted data in our classification system?
Options A. Confidential data requires encryption while Restricted data does not
B. Confidential data can be shared on a need-to-know basis while Restricted data requires explicit approval for each recipient
C. Confidential data is limited to financial information while Restricted data includes personal information
D. Confidential data has retention requirements while Restricted data can be deleted at any time
Correct Answer B. Confidential data can be shared on a need-to-know basis while Restricted data requires explicit approval for each recipient
Rationale In our classification system, both Restricted and Confidential data require protection, but they differ in sharing restrictions. Confidential data can be shared on a need-to-know basis within the organization, while Restricted data requires explicit approval for each recipient. Both types require encryption, can include various information types, and have retention requirements.

Scenario You receive an email containing a spreadsheet with the following data:

- Customer names and contact information
- Account numbers (unencrypted)

- Credit scores

The email explains that this information is needed for a quarterly review of high-value accounts.
Question Stem What is the correct classification for this spreadsheet?
Options A. Restricted
B. Confidential
C. Internal
D. Public
Correct Answer A. Restricted
Rationale This spreadsheet contains unencrypted account numbers, which are classified as Restricted data in our framework. When a document contains data of different classification levels, it must be classified according to the highest level of data it contains. While customer information and transaction details would typically be Confidential, the presence of unencrypted account numbers elevates the entire document to Restricted classification.

Learning Objective 2.3: Select appropriate handling procedures based on classification

Item ID: MOD2-OBJ3-MC-001

Question Type Multiple Choice
Question Stem You need to share a document classified as Confidential with an external auditor. What is the appropriate procedure?
Options A. Encrypt the document, verify the recipient's identity, and send via secure file transfer
B. Obtain approval from the Information Security Officer before sending
C. Print the document and send via certified mail only
D. Reclassify the document as Internal before sharing
Correct Answer A. Encrypt the document, verify the recipient's identity, and send via secure file transfer
Rationale Confidential information may be shared externally for legitimate business purposes but requires encryption during transmission and verification of the recipient. ISO approval is only required for Restricted data, not Confidential. Physical shipping without encryption does not provide adequate protection. Reclassification is inappropriate as it would bypass security controls.

Learning Objective 3.1: Identify common security threat indicators

Item ID: MOD3-OBJ1-MC-001

Question Type Multiple Choice
Question Stem Which of the following is NOT a common indicator of a phishing attempt?
Options A. Urgent calls for immediate action
B. Minor spelling and grammatical errors
C. Request for personal or financial information
D. Email sent from a colleague's corporate email account
Correct Answer D. Email sent from a colleague's corporate email account
Rationale While emails from legitimate corporate email accounts can still contain malicious content (if the account is compromised), this alone is not a common indicator of phishing. The other options are classic phishing indicators: creating urgency (A), containing errors (B), and requesting sensitive information (C). However, any suspicious content from any source should still be verified.
